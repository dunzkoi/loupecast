Mac screen recording that zooms where you click

Loupecast is a free, open-source macOS menu bar recorder. Cut the parts you don’t need and export an MP4 or GIF in 16:9, 9:16 or 1:1.

Download
brew install --cask dunzkoi/tap/loupecast

Record, polish, export

When you stop recording, the editor opens right away, with the zooms already in.

Automatic zoom on click

Every click while recording becomes a zoom. Select one you don’t want and press Delete, or add your own with Add Zoom.

Cut editing from the keyboard

Split at the playhead, pick a part to remove, and undo when you slip.

D Split Delete Cut ⌘Z Undo I O Set start and end

Settings right in the menu bar

⌘⇧2 starts and stops recording. Exports go to ~/Movies as an MP4 (16:9, 9:16 or 1:1) or a GIF.

Install

Runs on Apple Silicon Macs with macOS 15 or later. The app lives in the menu bar, not the Dock.

Install with Homebrew

One line in Terminal.

brew install --cask dunzkoi/tap/loupecast

Install from the zip

  1. Download Loupecast.zip and unzip it.
  2. Move Loupecast.app to your Applications folder.

If macOS says the app is damaged

Loupecast isn’t notarized by Apple yet, so macOS may block it. Run this once:

xattr -dr com.apple.quarantine /Applications/Loupecast.app

Allow screen recording

The first time you record, turn on Screen & System Audio Recording in System Settings, then quit and reopen Loupecast.

Frequently asked questions

Are my recordings sent anywhere?

No. The only network requests Loupecast makes are an update check against GitHub at launch and then daily, plus the download when an update exists. Recordings stay in ~/Library/Application Support/Loupecast/Recordings and exports in ~/Movies. Nothing is uploaded, and there is no analytics or telemetry.

What permissions does it need?

Screen & System Audio Recording in System Settings. After you turn it on, quit and reopen Loupecast once for it to take effect.

Do I have to allow screen recording again after an update?

No. Since 0.3.1 every release is signed with the same certificate, so macOS keeps the permission after an update. Coming from 0.3.0 or earlier, you may have to turn it on once more: when you start recording, Loupecast clears the old entry once by itself, so just turn it on when macOS asks.

macOS says the app “is damaged” or “can’t be opened”.

That warning appears because the app isn’t notarized. Run xattr -dr com.apple.quarantine /Applications/Loupecast.app once in Terminal and it opens.

The menu bar icon doesn’t show up.

macOS may hide new menu bar items when the bar is full. Check Menu Bar in System Settings, or just press ⌘⇧2 to start recording.

Does it run on Intel Macs?

No. It needs an Apple Silicon Mac with macOS 15 or later.
