클릭한 곳이 알아서 커지는 Mac 화면 녹화

Loupecast는 무료 오픈소스 macOS 메뉴바 녹화 앱입니다. 필요 없는 구간을 잘라 1080p60 MP4로 내보냅니다.

다운로드
brew install --cask dunzkoi/tap/loupecast

녹화하고, 다듬고, 내보내기까지

녹화를 멈추면 편집 창이 바로 열립니다. 줌은 이미 들어가 있습니다.

클릭하면 자동 줌

녹화 중에 클릭한 지점이 그대로 줌 구간이 됩니다. 필요 없는 줌은 선택해서 Delete로 지우고, 원하는 곳에는 "줌 추가"로 넣습니다.

키보드로 컷 편집

재생 위치에서 나누고, 구간을 골라 지우고, 실수하면 되돌립니다.

D 나누기 Delete 잘라내기 ⌘Z 되돌리기 I O 시작·끝 지정

메뉴바에서 바로 설정

⌘⇧2로 녹화를 시작하고 멈춥니다. 내보낸 영상은 1080p60 H.264 MP4로 ~/Movies에 저장됩니다.

설치

Apple Silicon Mac, macOS 15 이상에서 동작합니다. 앱은 Dock이 아니라 메뉴바에 나타납니다.

Homebrew로 설치

터미널에 한 줄이면 됩니다.

brew install --cask dunzkoi/tap/loupecast

zip 파일로 설치

  1. Loupecast.zip을 받아 압축을 풉니다.
  2. Loupecast.app을 응용 프로그램 폴더로 옮깁니다.

"손상된 앱" 경고가 뜨면

아직 Apple 공증을 받지 않아서 macOS가 막을 수 있습니다. 처음 한 번만 아래 명령을 실행하세요.

xattr -dr com.apple.quarantine /Applications/Loupecast.app

화면 녹화 권한 켜기

처음 녹화할 때 시스템 설정에서 화면 및 시스템 오디오 녹음 권한을 켭니다. 그다음 Loupecast를 종료했다가 다시 엽니다.

자주 묻는 질문

녹화한 영상이 어딘가로 전송되나요?

아니요. Loupecast가 하는 네트워크 요청은 실행할 때와 그 뒤 하루 한 번 GitHub에서 업데이트를 확인하고 내려받는 것뿐입니다. 녹화 원본은 ~/Library/Application Support/Loupecast/Recordings에, 내보낸 영상은 ~/Movies에만 저장됩니다. 업로드, 분석, 텔레메트리가 없습니다.

어떤 권한이 필요한가요?

시스템 설정의 화면 및 시스템 오디오 녹음 권한이 필요합니다. 권한을 켠 뒤에는 Loupecast를 한 번 종료했다가 다시 열어야 적용됩니다.

업데이트하면 화면 녹화 권한을 다시 켜야 하나요?

네. 아직 Apple Developer ID가 없어서 릴리스 빌드를 ad-hoc으로 서명하는데, macOS는 이 권한을 빌드마다 따로 기억합니다. 시스템 설정에서 기존 Loupecast 항목을 지우고 다시 켜 주세요.

"손상된 앱" 또는 "열 수 없음" 경고가 떠요.

공증을 받지 않은 앱이라서 생기는 경고입니다. 터미널에서 xattr -dr com.apple.quarantine /Applications/Loupecast.app을 한 번 실행하면 열립니다.

메뉴바 아이콘이 안 보여요.

메뉴바가 꽉 차면 macOS가 새 아이콘을 숨길 수 있습니다. 시스템 설정의 메뉴 막대 항목을 확인하거나, 그냥 ⌘⇧2를 눌러 녹화를 시작하세요.

Intel Mac에서도 되나요?

아니요. Apple Silicon Mac, macOS 15 이상에서만 동작합니다.

소스 코드는 전부 GitHub에 있습니다

MIT 라이선스이고 외부 의존성이 없습니다. 버그 제보와 PR을 환영합니다.

In English

Loupecast is a free, open-source macOS menu-bar screen recorder. It zooms in where you click, lets you cut the boring parts, and exports a 1080p60 MP4. Its only network request is an update check against GitHub Releases at launch and then daily.

Requires macOS 15+ on Apple Silicon; the interface is currently in Korean. Install with brew install --cask dunzkoi/tap/loupecast.
